⚙️ Paramètres IA & Scénarios

Le mode PYP ajoute le cadre de l'investigation (thème transdisciplinaire, idée centrale, concepts clés, axes de recherche), le cycle d'investigation sur les phases, le profil de l'apprenant et le bloc Action / Transmission. Désactivé, le cahier redevient identique et les données PYP sont conservées.
Le fichier .json contient tout le cahier (textes, photos, cadre PYP). À garder sur une clé USB ou dans le dossier de la classe : il protège des pertes si le navigateur est nettoyé.

📘 Guide enseignant — projet PYP

Cochez une séance quand elle est faite : l'avancement du projet se met à jour. « Ouvrir l'étape » crée la phase correspondante dans le cahier si elle n'existe pas encore.

📦 Livrables du projet

Chaque document existe en deux formats : le PDF pour imprimer, la version HTML pour consulter dans un navigateur, envoyer par courriel ou déposer sur l'ENT. La version HTML fonctionne sans Internet et s'imprime aussi.
Un document par étape du cycle : ce que l'élève a produit à cette étape, photos comprises. À imprimer et coller dans le cahier, ou à envoyer à la famille.
Support que l'élève garde en main pour présenter à ses camarades. Remplissez-le avec lui à la séance de préparation.
Récapitulatif de fin de projet : cadre PYP, concepts clés, profil de l'apprenant, étapes franchies, action réalisée.
Point d'étape destiné à la famille, rédigé automatiquement à partir du cahier. Relisez et complétez avant d'imprimer.
Le dossier complet réunit le cadre PYP, toutes les étapes du cycle avec leurs photos, la conclusion, le profil de l'apprenant et l'action de transmission. C'est le document de fin de projet.
